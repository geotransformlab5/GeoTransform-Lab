GEOTRANSFORM LAB - VERSI WEB

Isi folder:
- streamlit_app.py : kode aplikasi web
- requirements.txt : daftar pustaka Python yang diperlukan

Menjalankan di laptop:
1. Buka folder ini di VS Code.
2. Buka Terminal > New Terminal.
3. Jalankan: pip install -r requirements.txt
4. Jalankan: streamlit run streamlit_app.py

Menerbitkan sebagai website:
Unggah kedua file ke repository GitHub, lalu deploy repository tersebut melalui
Streamlit Community Cloud (https://share.streamlit.io/).
Pilih repository, branch main, dan file streamlit_app.py.

Catatan:
Versi web ini terpisah dari aplikasi desktop Tkinter sebelumnya.
